# 一页纸定位工作表

> grill 调研的最终落地。每次月度复盘时打开这份自检。

## 定位声明

> 一个 B 端产品经理，用 PM 视角看世界、写工具、折腾生活。
> 不写源码、不写鸡汤、不写求职。

## 验证目标（90 天后判定"方向成立"标准：≥ 2 项达成）

- [ ] 有陌生人主动来信 / 评论提问（非亲友）
- [ ] 有文章被非自营渠道转载（周刊 / 公众号 / newsletter）
- [ ] RSS / 邮件订阅增长到两位数
- [ ] 搜索引擎带来自然流量
- [ ] 有"慕名而来"的访问者

## 季度深度复盘（每 90 天）

- **支柱比例是否需要再平衡？**（50/30/20 是起点不是终点）
- **心智占位词是否收敛？**（写满 5 篇做一次选择）
- **节奏是否需要调整？**（节奏跟不上 = 减量，不是加力）
- **定位声明是否需要修订？**（每 90 天允许微调一次）
- **是否触及可持续性瓶颈？**（如果触及，启动低门槛产出机制）
